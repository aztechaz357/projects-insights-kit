Insights Kit セットアップ

GitHub Project にバーンダウン・バーンアップ・フィーバーチャートを後付けするための準備を、ブラウザだけで行います。 入力した値はこのページの中だけで使い、どこにも送信しません。

1情報を入力する

Project を開いたときのアドレスです (ビューの部分 /views/1 などは付いていても構いません)。

Project の Issue があるリポジトリなど、どれでも構いません。リポジトリには何も書き込みません。

通常は main。古いリポジトリは master のことがあります。

2ワークフローのファイルを作る

下のボタンを押すと GitHub の「新しいファイル」画面が、ファイル名と中身が入った状態で開きます。 そのまま右上の Commit changes… → Commit changes を押してください。

GitHub でファイルを作る

内容が長いため、1 クリックでの入力ができません。下の「うまくいかない場合」の方法を使ってください。

先にこのブラウザで GitHub にサインイン しておいてください (サインインしていないと「Whoops, something went wrong!」の画面になります。その場合はサインインしてからもう一度押してください)。

ブランチ保護がある場合は、Commit の画面で「Create a new branch…」を選んで Pull Request にし、マージしてください。

うまくいかない場合 (コピーして貼り付ける)
  1. コピーしました
  2. ファイル名だけ入った作成画面を開く (または リポジトリの Add file → Create new file で .github/workflows/insights-kit.yml と入力)
  3. 中身の欄に貼り付けて (Ctrl+V)、Commit changes

    

  


  

    
3鍵 (Secret) を登録する

    
ワークフローが Project を操作するための鍵 (GitHub の個人アクセストークン) を、リポジトリに安全に預けます
      (登録した値は画面に表示されず、ログでも伏せられます)。

    
先に手順 1 の GitHub Project の URL を入れてください。

    

      Secret の登録画面を開く
    

    
開いた画面で Name に PROJECT_TOKEN、Secret にトークンを貼り付けて Add secret。

  2. mode: setup を選び、計画完了日 (バッファを含まない完了予定日) などを入れて実行
    3. 
      
  3. 実行結果の Summary に出る表のとおりに、Project の Insights でチャートを作る
    4.
